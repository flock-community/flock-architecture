# Study material

The three pillars are ideas, and ideas are easiest to grasp when you see them applied. This section points to material, made by engineers at Flock, in which they are. Each item has its own page: what it is, who made it, what it shows, and what to look for.

## What is here

- **[The pragmatic repository](/study-material/pragmatic)** is a small but complete application in Kotlin, on GitHub, with its domain in a module of its own and its API written down as a specification. Read it, run it, or copy from it. It shows [Specified contracts](/specified-contracts) and [Domain isolation](/domain-isolation).
- **[Workshop: Pragmatic Functional Programming in Kotlin](/study-material/workshop)** is a hands-on workshop by Jerre van Veluw, in which you take an existing application and isolate its domain step by step. It shows [Domain isolation](/domain-isolation).

None of the material covers [Event-driven](/event-driven) yet.

## How to use it

- **If you want to see what the ideas mean in a real codebase**, read the [tour of the repository](/study-material/pragmatic). It is written in words. You don't need to read the code to follow it.
- **If you want to try the ideas**, clone the repository and run it, then follow one request from the contract through the domain to the database. After that, the [workshop](/study-material/workshop) is the place to practise the same moves on a codebase that doesn't have them yet.
- **If you want your team to adopt the ideas**, send a few engineers to the workshop and keep the repository as the reference for what the code should look like.
