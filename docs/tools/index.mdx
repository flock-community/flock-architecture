# Tools

None of the three pillars needs a tool. You can write a contract down in any format, keep a domain free of technology in any language, and record events with any messaging system. The deep dives explain the ideas without prescribing a tool, so they hold whatever you build with.

Still, some of the work the pillars ask for is repetitive, and repetitive work is what tools are for. This section describes the tools we built at Flock for exactly that work. Each tool has a page of its own that says what it is, what it brings and which pillar it serves. The link runs one way: a tool points to the pillar it serves, and the pillars never depend on a tool.

## The tools

- **[Wirespec](/tools/wirespec)** is a small language for writing down the contract of an interface, and a compiler that turns that contract into code. It serves [Specified contracts](/specified-contracts).
- **[KMapper](/tools/kmapper)** is a plugin for the Kotlin compiler that writes the code that translates between a domain model and the models around it. It serves [Domain isolation](/domain-isolation).

Both are published by Flock on [GitHub](https://github.com/flock-community).
